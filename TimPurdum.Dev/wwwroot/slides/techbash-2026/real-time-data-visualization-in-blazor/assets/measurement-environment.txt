Protocol
  Published build (not dotnet build output, which runs the client with
  debugging on and measured about 30x slower). One condition per harness
  run, builds alternated each round, three rounds, same preset, 30 s
  warm-up, 60 s per condition, a fresh browser page per run. Each run was
  capped at 10 minutes.
